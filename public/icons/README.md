## 绘制要求（速查）
- **PNG 透明背景**（JPG 会变成色块，禁用）
- 128px × 128px（大卡/难度）/ 160px × 160px（结算弹窗）（2x，手机不糊）
- 半身像构图，主体占 70–80%，头顶留 10% 边距
- 单张 ≤ 100KB
